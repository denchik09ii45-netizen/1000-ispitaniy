МОИ 1000 ИСПЫТАНИЙ — мобильная версия

Внутри: index.html, manifest.webmanifest, sw.js и иконка.

ВАЖНО: чтобы установить приложение на главный экран Android/iPhone как PWA,
его нужно разместить на HTTPS-сайте. Просто открыть index.html из архива
обычно недостаточно для установки и офлайн-режима.

Простой способ через GitHub Pages:
1. Создай аккаунт на github.com и новый публичный репозиторий.
2. Загрузи ВСЕ файлы из этой папки в корень репозитория.
3. В репозитории открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch,
   Branch: main, folder: /(root), затем Save.
5. Подожди публикации и открой адрес сайта на телефоне.

Android (Chrome):
Открой сайт → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

iPhone (Safari):
Открой сайт → «Поделиться» → «На экран Домой» → «Добавить».

Отметки хранятся локально в браузере этого телефона. Не очищай данные сайта,
если хочешь сохранить прогресс. Кнопка «Скачать мой прогресс» делает резервную копию.

Безопасность: экстремальные, высотные, водные и боевые активности пробуй только
с квалифицированным инструктором, подходящей экипировкой и соблюдением возрастных
и медицинских ограничений. Не выполняй опасные активности в одиночку.
